# 💰 OmaBudjetti

A personal budget tracker app created as a college project.

🌐 **[Live Demo](https://omabudjetti-55db1.web.app)**

## 🚀 Technologies
* **React 19** (Functional components & Hooks)
* **React Router 7** (Navigation)
* **SCSS** (Custom styling)
* **Firebase Firestore** (Cloud database)
* **Firebase Authentication** (Google sign-in)
* **Recharts** (Charts and statistics)
* **Vite** (Build tool)

## ✨ Features
* **Expense tracking:** Add, edit and delete expense entries.
* **Statistics:** View your spending with line and pie charts.
* **Cloud storage:** Data saved to Firebase Firestore.
* **Google login:** Sign in with your Google account.
* **PWA support:** Install the app on your mobile device.

## 🛠️ How to run locally
1. Clone the repository:
   ```bash
   git clone https://github.com/sukarapu/omabudjetti.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
